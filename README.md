# Kadé Keïta - Portfolio Photographe

Site portfolio de Kadé Keïta, photographe basé à Conakry, Guinée.

## Aperçu

Portfolio présentant ses réalisations en photographie : mariages, événements, portraits et couples.

## Technologies

- HTML5
- CSS3
- JavaScript vanilla

## Fonctionnalités

- Design minimaliste et élégant
- Galerie avec filtres par catégorie
- Lightbox pour visualisation des images
- Formulaire de contact
- Responsive design
- Animations au scroll

## Déploiement

Déployé sur [Vercel](https://vercel.com).
